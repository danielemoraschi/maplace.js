# Filter by group

A company's offices around the world, each in a region and a country: its `group` is a path, outermost first, so the list nests the countries under their regions, each heading counting everything under it, and a checkbox for each region and country above the list filters the map and the list.

- **Try it**: open Groups above the list and untick Italy: Europe's box is partly ticked, its count drops by Italy's offices, and Italy's pins leave the map. Click Europe: all of Europe is back. Untick every box and nothing is listed; tick them all and the filter asks for no group at all. Type in the search box while some boxes are unticked: the boxes set only the filter's groups, the box only its words, so each keeps what the other asked for.
- **A partly ticked group**: it shows its ticked subgroups, not entries of its own (those whose path ends at it, such as `group: ["Europe"]`): a group in the filter always takes all its subgroups. This map has none at a region.
- **HTML**: `group='["Europe","Italy"]'` on `<maplace-location>`, the path as JSON: a `group` starting with `[` is read as a path ([Location attributes](../../../../docs/reference/element.md#location-attributes)); `group-filter`, `group-counts` and `search` on `<maplace-map>` ([Map attributes](../../../../docs/reference/element.md#map-attributes)).
- **Script** and **Bundler**: `group: ["Europe", "Italy"]` on each office, up to 3 names ([Every location](../../../../docs/reference/locations.md#every-location)), and `groupFilter`, `groupCounts` and `search` on the list ([List view options](../../../../docs/reference/store.md#list-view-options)). The boxes call [`setFilter`](../../../../docs/reference/store.md#methods) for you: `setFilter([["Europe", "Italy"]])` asks for one path, Italy's offices, while `setFilter(["Europe", "Italy"])` asks for two groups, Europe and a top-level Italy; `setFilter(["Europe"])` shows Europe's countries too.
- **React**: `<LocationList groupFilter groupCounts search />` inside `<MaplaceProvider>` ([`<LocationList>`](../../../../docs/reference/react.md#locationlist)).
